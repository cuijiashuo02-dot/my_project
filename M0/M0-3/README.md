# M0-3 传感器数据分析排查记录

## 程序目标

读取包含 time、value 两列的 CSV 文件，计算 value 的均值和标准差，
剔除与均值的绝对偏差超过两倍标准差的数据，
将保留的 time、value 写入 cleaned_data.csv。

## 问题 1：CSV 列名大小写不一致

- 定位：原始脚本第 37 行，`row["Value"]`。
- 现象：运行时报 `KeyError: 'Value'`。
- 原因：CSV 表头为小写 `value`，字典键区分大小写。
- 修复：将 `row["Value"]` 改为 `row["value"]`。
- 验证：重新运行后，原来的 KeyError 消失，程序能够读取 60 条数据。
- 后续问题：程序在输出阶段报告 `/out/cleaned_data.csv` 路径不存在，尚待修复。
## 问题 2：输出路径错误

- 定位：原始脚本第 61 行，output_path 的构造。
- 现象：写文件时报 FileNotFoundError，路径为 /out/cleaned_data.csv。
- 原因：路径以 / 开头，指向系统根目录下的 out 文件夹；该目录不存在，而且不符合默认输出到当前工作目录的要求。
- 修复：将 output_path 设置为 OUTPUT_FILE，使用相对路径。
- 验证：重新运行后，当前目录生成 cleaned_data.csv，路径错误消失。但文件暂时只有表头，标准差与清洗逻辑仍需检查。
## 问题 3：标准差公式错误

- 定位：原始脚本第 50—53 行，acc 的累计方式和 std 的计算。
- 现象：不同测量值计算出的标准差接近零，显示为 -0.0000 或 0.0000。
- 原因：直接累加各数值与均值的差，正负偏差会抵消；同时缺少平方和开平方。
- 修复：累计偏差的平方，除以数据数量得到方差，再开平方。本程序采用总体标准差。
- 验证：使用给定的 60 条数据运行，均值为 50.4315，标准差为 18.5033。清洗后数量仍为 0，后续继续排查。
## 问题 4—7：清洗过程和输出结构错误

| 编号 | 原始位置 | 现象 | 原因 | 修复 |
|---|---|---|---|---|
| 4 | 第 56—58 行，遍历 data 时调用 remove | 相邻异常值可能漏删 | 删除元素会使后续元素前移，干扰遍历 | 保留原列表，把符合条件的数据加入新列表 |
| 5 | 第 57 行，离群值判断 | 偏小的异常值无法删除 | 只判断超过上限的情况 | 使用绝对偏差，同时检查上下两侧 |
| 6 | cleaned 列表及其使用处 | 清洗后数量为 0，输出只有表头 | 创建了 cleaned，却没有添加数据 | 将保留的时间和测量值作为一对加入 cleaned |
| 7 | 第 65—66 行，写入数据行 | 数据行与两列表头不一致 | 每行只写入一个元素，没有分别写入时间和测量值 | 逐行写入两个字段 t、v |

这些问题相互关联，因此一并修改清洗和写入部分，以保证时间与测量值始终对应。

输出文件改用 with 管理，确保写入完成后自动关闭。

- 总体标准差：18.5033。

## 问题 8：缺少输入检查和异常处理

- 定位：原始脚本的文件读取、数值转换、均值计算和文件写入部分。
- 现象：文件不存在、空文件、缺列或非数值输入会导致未经处理的异常。
- 原因：默认假设文件存在、表头正确、内容都是数字，而且至少有一行数据。
- 修复：
  - 检查表头和字段数量。
  - 检查数字转换结果，拒绝 NaN 和无穷大。
  - 在计算前检查数据是否为空。
  - 捕获文件操作、编码和 CSV 解析错误。
  - 统一输出错误说明，并以退出码 1 结束。
  - 读写文件均使用 with，确保自动关闭。

## 运行环境与依赖

使用 Python 3，程序仅依赖标准库，无需安装第三方包。

## 运行方法

先进入 M0/M0-3 目录。

默认读取当前工作目录中的 sensor_data.csv，
并将结果写入当前工作目录中的 cleaned_data.csv：

```bash
python3 sensor_analyzer.py
```

也可以指定输入、输出路径：

```bash
python3 sensor_analyzer.py --input sensor_data.csv --output cleaned_data.csv
```

查看参数帮助：

```bash
python3 sensor_analyzer.py --help
```

相对路径以执行命令时所在的目录为基准。
指定输出目录时，该目录需要提前存在。

## 统计与清洗规则

- 对清洗前的全部 value 计算均值和总体标准差。
- 总体方差使用数据数量 n 作为分母，标准差为方差的平方根。
- 删除 abs(value - mean) > 2 * std 的数据。
- 恰好等于两倍标准差的数据保留。
- 单次按原始数据统计量筛选，不迭代重新计算阈值。
- 时间和测量值成对保留，保持原有顺序。

- 输出：57 条数据，加表头共 58 行。
